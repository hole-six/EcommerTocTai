# Content specification

## Overview
- Target: `ManMattersHome.tsx`
- Interaction model: time-driven hero and click-driven category rail.

## Content
- Hero uses the extracted Man Matters wellness, creatine, and hair banners.
- Concern cards are Hair, Beard, Skin, and Nutrition using their extracted image assets.
- Product rail uses six extracted products and exact publicly rendered names/prices.

## Responsive behavior
- Desktop uses four concern cards and a four-card product grid.
- Mobile uses horizontal rails with 76vw cards and compact headings.
