# Page topology

1. Shared site header.
2. Compact, single-column hair-assessment form card with a progress indicator.
3. One question per step with selectable answer cards and Back/Continue controls.
4. Completion state with a personalised regimen summary and restart interaction.

Interaction model: click-driven. The assessment has five sequential question states and a completion state. On mobile, answer cards switch from two columns to one column.
