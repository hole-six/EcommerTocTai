# Behaviors

- Selecting an answer highlights the selected card and enables Continue.
- Continue advances through five questions; Back returns to the immediately previous question.
- A thin progress bar changes from 20% to 100% as answers are submitted.
- The final state replaces the question with the recommendation summary; Start over resets all answers.
- Buttons have a 160ms ease colour/transform transition.
